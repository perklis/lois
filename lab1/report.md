## Постановка задачи

Реализовать прямой нечеткий логический вывод на конечных носителях, используя треугольную норму драстического произведения и нечеткую импликацию Вебера. Программа должна считывать факты и правила из файла базы знаний, строить нечеткие отношения для правил, получать новые факты композиционным выводом и повторять процесс до стабилизации базы знаний либо до остановки пользователем.

## Теоретические сведения

Нечеткое множество на конечном универсуме задается функцией принадлежности \(\mu_A: U\to[0,1]\). Значение функции для элемента показывает степень его принадлежности множеству. В данной программе множество представлено парами «элемент — степень принадлежности».

Треугольная норма драстического произведения определяется так:

\[
T_D(u,v)=
\begin{cases}
v, & u=1,\\
u, & v=1,\\
0, & u<1\text{ и }v<1.
\end{cases}
\]

Таким образом, результат ненулевой, только если хотя бы один аргумент равен единице. В программе равенство единице проверяется с допуском \(\varepsilon=10^{-7}\).

Импликация Вебера в используемой реализации имеет вид:

\[
I_W(a,b)=
\begin{cases}
b, & a=1,\\
1, & a<1.
\end{cases}
\]

Для правила \(A(x)\sim> B(y)\) строится нечеткое бинарное отношение:

\[
R(x,y)=I_W(\mu_A(x),\mu_B(y)).
\]

Вывод по правилу композиции выполняется как max-драстическая композиция (дискретный аналог \(\sup\)-\(T_D\)):

\[
\mu_{B'}(y)=\max_{x\in U}\,T_D(\mu_{A'}(x),R(x,y)),
\]

где \(A'\) — имеющийся факт на носителе антецедента, а \(B'\) — полученный факт на носителе консеквента. Если вычисленный факт уже присутствует в базе знаний, второй раз он не добавляется.

## Описание реализации

Программа написана на Python и состоит из следующих модулей:

| Файл | Назначение |
|---|---|
| `main.py` | Загрузка базы знаний, построение отношений, итерационный прямой вывод и вывод результатов пользователю. |
| `models.py` | Классы `FuzzySet` и `Rule` для представления нечетких множеств и правил. |
| `fuzzy_operations.py` | Драстическое произведение, импликация Вебера, построение матрицы отношения, композиция и сравнение множеств. |
| `parser.py` | Разбор строк фактов и правил из файла базы знаний. |
| `knowledge_base.txt` | Исходные факты и правила для примера. |

Факт задается в формате `Имя={<элемент,степень>,...}`, правило — в формате `A(x)~>B(y)`. Парсер пропускает пустые строки и комментарии, проверяет синтаксис записей и допустимость степеней принадлежности в диапазоне от 0 до 1.

После загрузки данных программа строит матрицу отношения для каждого правила, для которого в базе описаны множества антецедента и консеквента. Далее она перебирает снимок текущего списка фактов и все правила. Факт применяется к правилу, если носители факта и антецедента совпадают. Для каждого элемента целевого носителя вычисляется max-драстическая композиция. Новый результат сравнивается со всеми известными фактами; при отсутствии совпадения он добавляется под именем `_1`, `_2` и т. д.

Итерации продолжаются, пока появляются новые факты. После каждой итерации пользователь может продолжить вычисления или остановить их. Блок-схема алгоритма в данный отчёт не включена.

## Результаты выполнения и отладки

Для проверки использована поставляемая с программой база знаний:

```text
A={<x1,0.0>,<x2,0.1>,<x3,0.3>,<x4,1.0>}
B={<y1,1.0>,<y2,0.8>,<y3,0.2>,<y4,0.0>,<y5,0.0>}
C={<x1,0.1>,<x2,1.0>,<x3,0.3>,<x4,0.0>}

A(x)~>B(y)
C(x)~>A(y)
```

Программа была запущена из каталога `lab3`; для имени файла оставлено значение по умолчанию, после первой итерации выбран ответ `n`. Фрагмент консольного вывода:

```text
Успешно загружено фактов: 3, правил: 2

=== Начало прямого логического вывода ===

--- Итерация 1 ---
{A, A(x)~>B(y)} |- _1={<y1,1.0>,<y2,0.8>,<y3,0.3>,<y4,0.3>,<y5,0.3>} [НОВЫЙ]
{A, C(x)~>A(y)} |- _2={<x1,1.0>,<x2,1.0>,<x3,1.0>,<x4,1.0>} [НОВЫЙ]
{C, A(x)~>B(y)} |- _3={<y1,1.0>,<y2,1.0>,<y3,1.0>,<y4,1.0>,<y5,1.0>} [НОВЫЙ]
{C, C(x)~>A(y)} |- _4={<x1,0.3>,<x2,0.3>,<x3,0.3>,<x4,1.0>} [НОВЫЙ]

Продолжить вывод на следующей итерации? (y/n): Вывод прерван пользователем.
```

Например, при применении факта `A` к правилу `A(x)~>B(y)` для элемента `y1` значение отношения с `x4` равно 1, поскольку \(\mu_A(x4)=1\) и \(\mu_B(y1)=1\). Поэтому \(T_D(1,1)=1\). Для `y3`, `y4` и `y5` максимум равен 0.3: значение достигается на `x3`, где принадлежность факту `A` равна 0.3, а импликация Вебера равна 1. Полученный результат совпадает с приведенным в выводе программы.

В этой проверке подтверждены чтение трех фактов и двух правил, вычисление новых множеств для всех совместимых пар «факт — правило», присвоение новым фактам имен и возможность остановки по запросу пользователя.
